# Mufy 批量导出

[English](README.md) · **[完整中文零基础教程](README.zh-CN.full.md)**

一个用来**导出、保存、阅读和迁移你自己的 Mufy 数据**的开源工具。

最初它只是一个批量导出聊天记录的用户脚本，现在已经扩展成一套比较完整的本地存档工具：Markdown / JSON 备份、EPUB 电子书、SillyTavern JSONL、人设面具与自建角色卡导出、存档体检、超大对话拆包，以及本地阅读器。

> ⚠️ **非官方工具，与 Mufy 官方无关。** 它读取的是你自己已登录账号里、网页本身也在调用的数据接口；官方改接口后，工具可能需要跟着更新。
>
> 🔐 **隐私：导出和阅读都在本地完成。** 你的聊天存档不会上传到本项目的服务器。
>
> 🔞 **面向成年用户。请勿向未成年人传播本工具或站点地址。**

## 它能做什么

| 功能 | 结果 |
|---|---|
| **批量导出聊天记录** | 一次导一个角色，也可以一次导很多角色 |
| **长期备份** | Markdown + 原始 JSON + 目录 + 角色开场白 |
| **直接出 EPUB** | 一个角色一本电子书，浏览器里直接生成 |
| **迁移到 SillyTavern** | 导出可导入的 `.jsonl` 对话文件 |
| **导出人设面具** | 可读文本 + 原始数据 |
| **导出自己写的角色卡** | 完整字段、原始 JSON、头像/封面、正则条目 |
| **🩺 存档体检** | 一次看清卡是否还在、记录是否还在 |
| **🆘 消失角色救援** | 卡被设为私密后，只要还有对话钥匙就能尝试把正文救回来 |
| **🚑 超大对话拆包** | 单段大到浏览器扛不住时，边翻页边分文件导出 |
| **手机端** | iPhone / iPad / Android 都有真实用户走通过 |

## 输出方式怎么选

- **ZIP / Markdown + 原始 JSON**：真正的备份格式，拿不准就选它。
- **合并 Markdown**：一个角色一份长文，适合通读和全文搜索。
- **EPUB**：最适合手机当小说读。
- **SillyTavern JSONL**：想把旧聊天搬去酒馆继续聊时用。

## 🚀 最快开始

### 电脑：Chrome / Edge + Tampermonkey

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新版 Chrome / Edge 记得在扩展详情里打开 **「允许用户脚本」**。
3. 安装脚本：

   <https://raw.githubusercontent.com/willwefind/mufy-batch-export/main/mufy-batch-export.user.js>

## 为什么做这个

Mufy 自带的导出更适合一条一条处理存档。角色一多、存档一多，或者想把自己的数据长期留在平台之外，就会很麻烦。

这个项目的核心想法很简单：**属于你自己账号的数据，应该能被保存成普通、可迁移、以后还能读的文件。**

而且它尽量不制造「好像成功了」的假安全感。真实用户反馈已经遇到过：

- 角色设为私密后入口消失，但聊天正文其实还在；
- 角色卡被删了，但历史聊天仍然能导；
- 超大存档把手机或浏览器直接撑爆；
- 服务端迁移后，接口总数和真正剩下的消息数对不上；
- 安卓浏览器静默拦掉批量下载的后半段；
- 导出只拿到一部分，却看起来像成功。

能判断出来的情况，脚本会明确告诉你，而不是悄悄出一份残缺备份。

## 隐私与安全边界

脚本必须读取你浏览器里现成的 Mufy 登录状态，否则它不可能拿到你自己的数据。

边界是：

- 登录凭证只用于请求 Mufy 自己的接口；
- 本项目没有收集聊天存档的统计后端；
- 导出的文件在浏览器本地生成；
- 核心 ZIP 导出不依赖第三方运行库；
- 源码公开，可以自己审查。

**不要因为作者说「安全」就相信一个用户脚本。** 看得懂就自己读源码；看不懂也可以把源码交给你信任的人或 AI 帮你检查，再决定要不要在登录状态下运行。
