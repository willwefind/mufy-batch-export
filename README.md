# Mufy 批量导出聊天记录

一个油猴脚本，把 **mufy** 上**某个角色（或全部角色）的所有对话**
一次性导出成 Markdown + JSON，打包成 ZIP。

mufy 自带的导出只能在存档列表里一条一条点。角色多、存档多的时候基本没法用。

> ⚠️ 非官方工具，和 mufy 官方无关。它走的是网页自己在用的接口，
> 官方改接口就可能失效。只读你自己的账号数据。

> 🔞 **本工具面向成年用户。** mufy 上存在成人向的角色扮演内容，
> 请勿向未成年人传播本工具或该站点地址。
> 出于同样的原因，本文档不写出站点网址——你如果是它的用户，你已经知道；
> 如果不知道，这个工具对你也没用。

---

## 它能做什么

- 按角色批量导出，或一次导出全部聊过的角色
- **每段对话一个 `.md` 文件**，打包成一个 ZIP（也可以合并成一份大 Markdown）
- 附带 `_原始数据.json` 完整备份（未经任何清洗的原文）
- 自动生成 `00_目录.md` 索引，可点进每一篇
- 文件名带日期和场景线索，例如
  `03_20260531-0101_沉闷微雨的夏夜 · 临海别墅.md`
- 可选清理 `<think>` 和状态栏 HTML，让 Markdown 能读（JSON 里永远是完整原文）

## 安装

### 方式一：Tampermonkey（推荐）

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点这个链接一键安装 →
   [**mufy-batch-export.user.js**](https://raw.githubusercontent.com/willwefind/mufy-batch-export/main/mufy-batch-export.user.js)
   （Tampermonkey 会自己弹出安装页；装完以后有新版本它也会提示更新）
   打不开的话，就点扩展图标 →「添加新脚本」→ 把仓库里的 `mufy-batch-export.user.js`
   全文粘进去 → Ctrl+S。
3. 刷新 mufy 的聊天页面，左下角出现 **「⬇ 批量导出」** 按钮。

### 方式二：控制台粘贴（临时用一次）

在 mufy 的聊天页面按 F12 → Console → 粘贴全文 → 回车。关掉标签页就没了。

> 🔒 **提醒**：浏览器控制台会警告你「不要粘贴不明代码」，这个警告是对的。
> 往控制台粘贴脚本等于给了它你当前登录态的全部权限。
> **粘之前请自己读一遍源码**，或者用 Tampermonkey 装（至少代码是留在本地、可复查的）。
> 本脚本不含任何外部请求，压缩用浏览器原生 API，不引第三方库——这一点你可以自己搜一遍确认。

## 面板选项

| 选项 | 说明 |
|---|---|
| **当前角色（本页）** | 导出你正在看的这个角色 |
| **全部聊过的角色** | 想整体备份选这个 |
| **全部已关注角色** | 你点过关注的全部角色，**包含从没聊过的**（会自动跳过并报数） |
| **手动填角色 ID** | 从地址栏 `roleId=` 后面那串复制过来 |
| **每段对话一个文件（ZIP）** | 默认。N 段对话 = N 个 `.md`，打包成一个 zip |
| **全部合并成一份 Markdown** | 想一口气通读时用 |
| **清理 think / 状态栏 HTML** | 只影响 Markdown 可读性；JSON 永远是完整原文 |
| **附带 JSON 完整备份** | 建议勾着，这才是真正的备份 |

ZIP 里长这样：

```
00_目录.md                                    ← 索引，可点进每一篇
01_20260806-2352_闷热湿黏的梅雨夜 · 宴会厅.md
02_20260531-0237_我给这段存档写的备注.md        ← 写过备注的用备注
03_20260531-0101_未存档_沉闷微雨的夏夜.md       ← 没存过档的那段
_原始数据.json
```

文件名规则：`序号_日期_线索`。线索优先用你写的存档备注；没写备注就自动取那段开场白的
场景抬头（「天气 · 地点」那一行）。每个文件的修改时间也写成对应日期，
资源管理器里能直接按时间排序。

## 用之前值得知道的几件事

### 1. mufy 的 token 只活 15 分钟

面板开着放一会儿再点，很容易满屏 401。脚本每次请求前都会检查有效期，
不足两分钟就自动用 `POST /api/users/refresh` 换新的。
所以放多久再点都不要紧。真提示「续不上登录态」，那就是掉登录了，刷新页面重来。

### 2.「有存档」不等于「有内容」

这是最容易漏东西的地方。mufy 的**存档**是你按「保存并开启新对话」才产生的，
一条存档只记了最后一问一答 + 它来自哪个 session。

如果只顺着存档列表导，会漏掉**「聊过但从没按保存」的那段对话**——而这非常普遍。
实测在一个 200+ 角色的账号上：

- **102 个角色一条存档都没有**，但里面躺着 **1356 条消息**（最多的一个 112 条）
- **有存档的角色也照样漏**：抽查 25 个，其中 24 个的最后一段没进过存档，多出 706 条

所以本脚本会额外把角色列表里的 `lastSessionId`（你最后聊的那段）也纳进来。
这类段落文件名带 `未存档_` 前缀，文件里也写明来源。

### 3.「关注」和「聊过」不是同一批人

`isFollowed=true` 返回的是**你关注的全部角色**，包括从没聊过的，而不是两者的交集。
反过来也有你聊过却没点关注的。想整体备份，选 **「全部聊过的角色」**。

### 4. 如果你开着「每次询问保存位置」

Chrome 设置里那个「下载前询问每个文件的保存位置」如果开着，
批量导出会给每个包弹一次「另存为」，几百个角色就是几百个对话框。
批量跑之前先去 `chrome://settings/downloads` 关掉它，跑完再改回来。

另外首次批量下载时浏览器会问一次「是否允许下载多个文件」，点允许。

### 5. 跑的时候别把标签页切到后台

浏览器会把后台标签页的定时器降频（最狠到每分钟一次），导出会卡死。

## 已知边界

- 一个角色如果有**多段**都没存档（不止最后一段），mufy 的接口只提供 `lastSessionId`
  这一个，**更早的没存档段落够不着**。想长期留住的对话，还是在 mufy 里按一下
  「保存并开启新对话」最稳。
- 某个 session 的正文如果被平台清掉了，脚本会退回用存档里那一问一答，
  并在该段标 `⚠️`，不会静默丢内容。

## 它是怎么工作的

三个接口，都带 `Authorization: Bearer <localStorage['mufy-token']>`：

| 接口 | 作用 |
|---|---|
| `GET /api/characters/query_session?pageNum=&pageSize=&isFollowed=` | 角色列表（含 `lastSessionId`） |
| `GET /api/sessions/query_archives?characterId=` | 某角色的存档列表 |
| `GET /api/dialogs/query?sessionId=&characterId=&pageNum=&pageSize=` | 某段对话的全部消息 |

流程：取角色列表 → 每个角色取存档 → 按 `sourceSessionId` 去重、再补上 `lastSessionId`
→ 逐段抓全文 → 渲染 Markdown → 打包 ZIP → 浏览器下载。

ZIP 是脚本按格式自己拼的（本地文件头 / 中央目录 / EOCD），压缩用浏览器原生的
`CompressionStream('deflate-raw')`，**不引任何外部库**。
已用 .NET `ZipFile` 和 Windows 自带的 `Expand-Archive` 双双验过，中文文件名不乱码。

请求之间有 120–300ms 的间隔，遇到 429/5xx 会退避重试——请不要把它改激进，
这是别人的服务器。

## 隐私

- token 只从你自己浏览器的 `localStorage` 读，**只发给 mufy 自己的接口**，不外传。
- 没有任何统计、上报、外部请求。
- 导出文件直接走浏览器下载，落到你自己的硬盘。
